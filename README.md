# Gemini GitHub AI

ИИ-ассистент на базе Gemini, который умеет работать с GitHub через безопасный набор инструментов.

## План

- 💬 чат с Gemini
- 📁 просмотр репозиториев
- 🔎 поиск файлов и кода
- 📄 чтение файлов
- ✏️ изменение файлов с подтверждением пользователя
- 🌿 создание веток
- 🔀 создание Pull Request

## Архитектура

```text
Пользователь → Web UI → Python backend → Gemini API
                                      ↓
                                  GitHub API
```

## Безопасность

API-ключи не должны храниться в исходном коде. Используйте переменные окружения и `.env` только локально.
